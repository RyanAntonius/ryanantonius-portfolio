# Independent-site migration

The independent site prototype has been built and validated separately from Wix.

## What it includes now

- Portfolio homepage and selected-work sections
- Responsive mobile header and hamburger navigation
- Home hero image rotation
- Shared visual system for retail, event, and industrial work
- No Wix CMS or Wix publishing dependency in the new application

## Remaining before Wix can be cancelled

1. Migrate all individual case-study routes.
2. Download and re-host all images and video currently served from Wix.
3. Add editable content outside Wix.
4. Publish the completed independent version and point the custom domain to it.

The current source archive is `ryanantonius-portfolio-independent-site.tar.gz`.
