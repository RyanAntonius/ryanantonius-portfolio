# Ryan Antonius Portfolio

Private GitHub backup of [ryanantonius.com](https://www.ryanantonius.com/). The live Wix site remains unchanged.

## What is stored here

- `src/`, `public/`, and the project configuration files are the editable Astro website source.
- `public/assets/` contains the project images that were already local.
- The complete Wix media copy—including the remaining images and videos—is stored privately in the [Complete Wix media backup release](../../releases/tag/wix-backup-2026-09-01).
- `ryanantonius-portfolio-wix-source-backup.tar.gz` is a second full source snapshot.

## Hosting later

This source currently uses Wix's Astro/Cloudflare setup, so it is not yet a one-click GitHub Pages site. The next step is to make an independent static build, then publish that build from a separate public repository (while keeping this backup private).
